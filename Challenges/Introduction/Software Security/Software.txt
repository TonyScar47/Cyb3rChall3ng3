-> Software 06 - Strings 3

1. vai su flag -> Data -> Create Array -> Conferma
2. Quando leggi "^" significa che è uno XOR
3. Evidenzia il codice key e flag e leggiti i byte facendo format -> byte
4. Prendi quei byte e inseriscili nel codice (Window -> Script -> New Script)

--- CODICE SCRIPT ---

#@runtime Jython

flag = [0xd4, 0x5c, 0xdc, 0xbb, 0x6b, 0x1e, 0xd3, 0x4a,
        0x4a, 0x5e, 0xd2, 0xdf, 0xac, 0x7c]
key  = [0xb2, 0x30, 0xbd, 0xdc, 0x10, 0x7a, 0xe1, 0x7b,
        0x2c, 0x3b, 0xe2, 0xec, 0x99, 0x01]

result = ''.join(chr(f ^ k) for f, k in zip(flag, key))
print(result)
